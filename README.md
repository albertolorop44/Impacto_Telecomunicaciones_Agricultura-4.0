# Impacto de las Telecomunicaciones en la Agricultura 4.0

Repositorio asociado al Trabajo de Fin de Grado **"Impacto de las Telecomunicaciones en la Agricultura 4.0"**, desarrollado en el Grado en Ingeniería en Tecnologías de Telecomunicación de la Universidad Pontificia Comillas (ICAI).

## Descripción

El objetivo de este repositorio es recoger el código utilizado para el tratamiento de datos, cálculo de indicadores técnicos, estimación de modelos estadísticos y análisis económico de la implantación de tecnologías de Agricultura 4.0.

El análisis se centra en el impacto de tecnologías como GPS, RTK, ISOBUS, siembra variable, abonado variable y corte automático por tramos sobre indicadores productivos, operativos y económicos.

## Contenido

- Cálculo del Índice de Intensidad Tecnológica (IIT).
- Análisis técnico de cada cultivo: maíz, arroz y tomates.
- Análisis comparativo entre maíz, arroz y tomate.
- Modelos estadísticos OLS, Ridge Regression y Random Forest.
- Análisis financiero mediante ROI, Payback, VAN, TIR y hectáreas umbral.

## Datos

Por motivos de confidencialidad, los datos reales utilizados en el Trabajo de Fin de Grado no se incluyen en este repositorio. El código se presenta como referencia metodológica y puede adaptarse a bases de datos equivalentes.
